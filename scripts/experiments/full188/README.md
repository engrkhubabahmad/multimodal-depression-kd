# New 80:10:10 internal DAIC-WOZ protocol

Open [the staged Colab notebook](../../../notebooks/full188_80_10_10_seed103.ipynb) on a GPU runtime. It fetches this PR branch using `GITHUB_TOKEN` from Colab Secrets. Run one numbered stage at a time. Outputs live only under `/content/drive/MyDrive/DAIC_WOZ/experiments/full188_80_10_10_seed103/`. The split has 150 TRAIN, 19 VAL and 19 held-out student TEST participants, stratified by label, with seed 103. Participant 440 is excluded.

The new feature cache reuses the original 141 label-independent ComParE16 arrays. It copies the 47 other arrays out of the old seed-42 experiment into the new experiment and verifies their checksums. If the old full-188 cache is unavailable, it extracts the 47 arrays from source recordings. Stage 4 verifies that all 188 feature paths exist and the labels and split memberships match. Stage 5 removes **only** the old `full188_seed42` and `full188_seed103` experimental folders after checking that no new feature path depends on either. The raw DAIC-WOZ corpus, metadata and shared `ussd_compare16` cache are retained.

Both teachers print participant-level TRAIN macro F1 and VAL macro F1 on **every epoch** and write a per-epoch history CSV. The text teacher uses the original Idiap InducT-GCN architecture. If the external Idiap source is absent from `MyDrive/tools`, the runner fetches only `main.py` from official Idiap commit `de8f477619ce61a2a65640a0735aa8dfe659ac59` into temporary `/content` and verifies its Git blob hash before training. The fresh audio teacher uses the USSD ComParE16+LSTM architecture but trains on 8 sampled segments per participant, aggregating the probabilities before applying a participant-level class-weighted loss. This aligns the supervised unit with participant-level evaluation. It reduces the learning rate to `3e-4`; the prior seed-103 audio teacher was nearly constant on TRAIN and VAL. These are a new protocol and candidate, not a continuation of the old checkpoints. No OOF. Stop after both VAL reports to review them before student training.

This is an internal redistributed split. The original official TEST roster contributes to the 188-person pool, so the held-out result is **not** the official AVEC test. The external origin of the local TEST labels has not been independently established. Keep the new 19-person student TEST closed until the method is frozen on validation.
