# Full 188-person protocol from a fresh Colab session

Open [`notebooks/full188_seed42_start_to_finish.ipynb`](../../../notebooks/full188_seed42_start_to_finish.ipynb) in Colab, select a GPU runtime, and run cells in order. Keep `GITHUB_TOKEN` in Colab Secrets. The notebook fetches this PR branch and runs the small GitHub modules. Every newly generated persistent file is stored in `/content/drive/MyDrive/DAIC_WOZ/experiments/full188_seed42/`; the Git checkout and temporary OpenSMILE copy are under `/content/`.

Expected existing inputs: DAIC-WOZ metadata and raw recordings under `DAIC_WOZ`; 141-person ComParE16 cache under `DAIC_WOZ/experiments/ussd_compare16`; Idiap author source and OpenSMILE release under `MyDrive/tools/solo_teacher_sources/bias_in_daic-woz` and `MyDrive/tools/opensmile-3.0.2-linux-x86_64`. Missing inputs fail with an explicit path. The notebook does not redownload corrupt participant 440.

The `run_all` module orders split, features, fresh text teacher, fresh audio teacher, independent student branches, and no-KD / standard-KD / RA-KD fusion. It skips completed stages on rerun and refuses an incomplete directory so failures can be inspected. To run one stage again after inspection, remove only its incomplete output directory manually and invoke `--stage <name>`. No OOF targets are created. Student TEST is intentionally a separate final command after choosing a single mode from validation.

The seed-42 internal protocol combines TRAIN-107, usable DEV-34, and the locally labeled original TEST-47 and redistributes them into participant-disjoint TRAIN-132 / VAL-28 / student TEST-28. This is **not** an official AVEC test score. `full_test_split.csv` matches the official test roster and its binary labels match PHQ score >=10, but the external origin of its labels still needs documentation before publication. The original teacher checkpoints and earlier student outputs cannot be reused on this split.

The notebook's final test cell is left unexecuted. Freeze the method and mode on VAL before running it once. Model training requires your Colab GPU, DAIC-WOZ Drive data, and external author source; repository tests only validate synthetic split/provenance behavior.
